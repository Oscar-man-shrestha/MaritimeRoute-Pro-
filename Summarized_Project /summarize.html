Executive Summary

The Maritime Route Optimizer is a comprehensive A* and Genetic Algorithms based system that calculates optimal shipping routes between global ports, balancing speed and fuel efficiency while incorporating real-world shipping lane data. The system combines advanced algorithms with practical maritime industry requirements to deliver actionable route optimization.

How It Works - Complete Workflow

Step 1: User Input & Validation

User Selection: - Departure Port: Shanghai - Destination Port: Suez_Canal - Intermediate Ports: [Mumbai] - Optimization: Balanced Analysis

Step 2: Route Template Matching

# System finds pre-defined optimal route ROUTE_TEMPLATES = { ("Shanghai", "Suez_Canal"): [ "Shanghai", "Singapore", "Colombo", "Mumbai", "Salalah", "Suez_Canal" ] }

Step 3: Genetic Algorithm Optimization

GA Process (100 generations): 1. Population: 40 routes (template + variations) 2. Fitness: Score based on optimization goal 3. Selection: Keep top 20% routes 4. Crossover: Combine best routes 5. Mutation: Introduce variations (5% chance) 6. Evolution: Repeat for optimal solution

Step 4: Route Calculation & Metrics

Calculations: - Distance: Haversine + shipping lanes - Time: (Distance / 37 km/h) × 1.25 weather factor - Fuel: Distance × 0.04 tonnes/km × 1.25 weather - CO2: Fuel × 3.15 conversion factor

Step 5: Results Delivery

JSON Response: { "fastest_route": {ports, distance, time, fuel, co2, coordinates}, "fuel_efficient_route": {ports, distance, time, fuel, co2, coordinates}, "direct_route": {coordinates}, "port_locations": {port: [lat, lon]} }

Fitness Functions

def _fitness(self, route_seq, goal): distance = self._total_distance(route_seq) stops = len(route_seq) - 2 if goal == "fastest": time = self._estimate_travel_time_hours(distance) + stops * 24 return 1.0 / (time + 1e-6) # Maximize 1/time else: # fuel efficient fuel = self._estimate_fuel_tonnes(distance) * (1 + 0.05 * stops) return 1.0 / (fuel + 1e-6) # Maximize 1/fuel
